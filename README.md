# Emotion Harmony 🔵

**Emotion Harmony** é uma plataforma digital criada com o objetivo de promover a **saúde mental** e o **bem-estar emocional** de forma acessível, segura e eficaz. Desenvolvida como Trabalho de Conclusão de Curso na ETEC Lauro Gomes, a aplicação combina tecnologias modernas com práticas de autocuidado fundamentadas em evidências científicas.

## 💡 Sobre o Projeto

O projeto surgiu da necessidade de oferecer suporte emocional à população diante de desafios como estigma social, altos custos e falta de acesso a profissionais de saúde mental. A proposta é fornecer um ambiente acolhedor com funcionalidades úteis para o dia a dia.

### 🧠 Funcionalidades principais

- Meditação guiada  
- Exercícios de respiração  
- Monitoramento de humor e emoções  
- Diário emocional  
- Acompanhamento de vícios e hábitos  
- Lembrete de ingestão de água  
- Botão de pânico com chamada de emergência  
- Painel administrativo (dashboard)
